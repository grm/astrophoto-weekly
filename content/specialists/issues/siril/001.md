## L’actualité

### 28 octobre 2026 — Siril 1.4.5 stable : un rejet de pixels plus fiable

Le rejet GESDT, qui repère les valeurs aberrantes pendant l’empilement, pouvait écarter les deux valeurs extrêmes sans justification et manquer une valeur trop haute. La correction intéresse donc ceux qui emploient cet algorithme. Le live stacking corrige aussi des interruptions avec les images 8 bits.

Côté Python, réinjecter des pixels flottants dans une image chargée en 16 bits ne multiplie plus leurs valeurs par 65 535. Les scripts peuvent également détecter un fonctionnement sans interface graphique avec `is_headless`.

**En pratique.** L’équipe recommande cette maintenance aux utilisateurs de la branche 1.4. Si un ancien résultat vous paraît suspect, reprendre un petit jeu de données avec les mêmes paramètres permettra de comparer ; nous n’avons pas effectué cet essai. La 1.5 demeure en développement.

**À savoir.** Sur Mac, macOS Ventura 13 est requis. Le téléchargement officiel signale des problèmes connus pour le paquet tiers Flatpak.

[Annonce et téléchargement officiels](https://siril.org/download/2026-10-28-siril-1-4-5/).

## Les ressources pratiques — pas des nouveautés datées

### Mosaïques sous Siril 1.4 : les panneaux empilés et les brutes n’ont pas la même recette

Le guide de Cécile Melis distingue l’assemblage de panneaux déjà empilés de celui d’une longue série issue du mode mosaïque d’un smart-télescope. Le point commun est l’alignement astrométrique : identifier la position du ciel dans chaque image, puis appliquer cette information au recalage.

**En pratique.** Pour des panneaux, commencez par résoudre leur astrométrie, appliquez l’alignement existant avec cadrage maximal et utilisez l’estimation de taille avant de lancer le calcul. Le guide explique ensuite la normalisation des zones de recouvrement.

Pour une longue série de brutes, ne recopiez pas toutes les options des panneaux : l’autrice déconseille la normalisation sur les recouvrements, trop coûteuse et inutile dans ce cas. Le puzzle peut être géant ; inutile de lui offrir toutes les ressources du salon.

**À savoir.** Cette méthode consomme beaucoup de mémoire. Le guide indique une limite d’affichage de 32 768 pixels par dimension dans Siril 1.4 ; réduire l’échelle peut être nécessaire.

[Guide officiel des mosaïques, librement consultable](https://siril.org/tutorials/mosaics/).

### Python : arrêter le script au bon endroit plutôt que multiplier les messages d’erreur

Le tutoriel de Cécile Melis montre comment relier VSCode au processus Python lancé par Siril et poser un point d’arrêt pour examiner ce qui se passe.

**En pratique.** Il faut Siril 1.4.0 ou ultérieur, lancé au moins une fois pour préparer son environnement Python. Configurez VSCode avec cet environnement, activez le mode de débogage Python dans Siril, puis attachez le débogueur au numéro de processus affiché au lancement du script.

**À savoir.** Le guide vise les personnes connaissant déjà Python et Siril. L’API intégrée `sirilpy` reste qualifiée d’expérimentale ; elle est distincte de `pySiril`, module externe utilisé pour piloter Siril depuis une autre application.

[Tutoriel de débogage](https://siril.org/tutorials/python_debug/) · [Documentation de l’API intégrée](https://siril.readthedocs.io/en/stable/scripts/Python-scripts.html).
