## La maintenance datée

### 6 novembre 2026 — RC Astro 2.6.11 publiée : débloquer les licences derrière certains proxys

Cette maintenance améliore la connexion aux licences sur les réseaux utilisant un proxy ou une inspection des connexions sécurisées. Un échec fournit aussi un diagnostic plus explicite. Cela concerne notamment la **CLI**, le programme en ligne de commande utilisé par les scripts Siril pour appeler BlurXTerminator, NoiseXTerminator et StarXTerminator.

**En pratique.** Si l’activation bloque sur ce type de réseau, vérifiez la version de la CLI. Il s’agit d’un correctif d’accès, sans nouveau modèle de traitement annoncé.

**À savoir.** Ces produits nécessitent leurs licences commerciales. Les changements de permissions mentionnés dans la même note sont spécifiques à PixInsight.

[Historique RC Astro](https://www.rc-astro.com/version-history/) · [Intégration décrite par Siril](https://siril.org/2026/06/rc-astro-tools-available-in-siril/).

## Les ressources pratiques — sans date de sortie inventée

### Aberration Remover 1.2.0 : aligner le rouge et le bleu sur le vert

Le script ajoute une étape pour les **aberrations chromatiques latérales** : les canaux ne placent pas exactement les étoiles au même endroit, notamment vers les bords. Il mesure leurs positions puis rééchantillonne le rouge et le bleu sur le vert, qui reste inchangé. Cette correction géométrique est distincte du modèle d’IA, lequel traite chaque canal séparément.

**En pratique.** Dans la version 1.2.0 consultée, l’option **Align color channels (lateral chromatic aberration)** est activée par défaut pour les images à trois canaux ; elle peut être désactivée. Pour un essai, travaillez sur une copie et comparez centre, coins et couleurs des petites étoiles. Une frange colorée n’a pas toujours cette cause.

**À savoir.** Le script libre GPL-3.0-or-later figure dans le catalogue Python de Siril 1.4. Le code exige au moins six étoiles appariées par canal pour corriger celui-ci ; un champ pauvre peut donc limiter l’opération. Sa présence dans le dépôt ne constitue pas une validation sur toutes les installations.

[Code original 1.2.0 et explication de l’algorithme](https://gitlab.com/free-astro/siril-scripts/-/blob/584765f5bc1a0c749c2fcd75d831f0666801ddbb/processing/AberrationRemover.py) · [Catalogue officiel des scripts](https://siril.readthedocs.io/en/stable/scripts/python-scripts-list.html).

### Asterion : donner une adresse céleste à l’image chargée

La résolution astrométrique retrouve position, échelle et orientation d’un champ. Le script Asterion pour **Siril 1.4 ou ultérieur** propose une résolution « aveugle », qui peut rechercher le ciel sans coordonnées initiales fiables. Il écrit ensuite la solution dans l’image pour les outils de Siril.

**En pratique.** Le guide demande d’installer l’exécutable Asterion, d’ajouter le dossier du script dans **Préférences → Scripts**, puis de charger une image et de lancer **Solve**. Un catalogue d’étoiles doit être téléchargé ; le panneau permet de le gérer. Prévoyez ce téléchargement avant une session hors ligne.

Pour automatiser, le guide documente aussi l’appel par `pyscript` depuis un script Siril. L’intégration tient compte de l’ordre des lignes des images pour adapter les coordonnées, y compris les termes de distorsion.

**À savoir.** Asterion est libre sous Apache-2.0. Le guide vérifié dans la version 0.5.0 ne démontre pas que cette intégration a débuté le 11 novembre : cette date est celle de la release générale. Les performances et comparaisons avec le solveur Siril sont rapportées par l’auteur, pas reproduites ici.

[Guide original pour Siril, version 0.5.0](https://github.com/asterion-solver/asterion/blob/v0.5.0/integrations/siril/README.md) · [Installation, catalogues et licence](https://github.com/asterion-solver/asterion/blob/v0.5.0/README.md).
